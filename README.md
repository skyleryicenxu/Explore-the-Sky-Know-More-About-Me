# Skyler — A Short Flight（个人网站）

## 文件夹里有什么

| 文件 | 作用 | 你需要碰吗 |
|---|---|---|
| `content.js` | **网站上所有的文字**：开场、四个 fun fact、降落卡片的邮箱 | ✅ 只改这个 |
| `music.mp3` | 背景音乐（点 Board the flight 后开始播放）；换歌就替换这个文件，或在 content.js 里改 `music` 的文件名 | 可选 |
| `index.html` | 3D 场景、动画、排版 | ❌ 不用碰 |

## 怎么改文字

1. 用任何文本编辑器打开 `content.js`（推荐 VS Code，Mac 的"文本编辑"也可以）。
2. 只改英文双引号 `"..."` 里面的文字，逗号不要删。
3. 方括号 `[ ... ]` 是占位符，网页上会显示成虚线框。写好内容后把方括号一起删掉。
4. 保存，刷新网页就能看到。

**每朵云两项**：
- `title`：卡片里的大字
- `text`：下面的小字

**想加一朵云或者删一朵**：在 `chapters` 里复制或删除一整段 `{ ... },`。天色会自动重新分配，降落永远在最后。

## 本地预览

直接双击 `index.html` 用浏览器打开就行（需要联网，3D 引擎从网上加载）。

## 上线（免费）

最简单的方法：打开 https://app.netlify.com/drop ，把整个文件夹拖进去，就能拿到一个网址。
以后想用自己的域名（比如 skylerxu.com），也在 Netlify 后台绑定。

## 设备适配

- 手机：自动降低画质、减少云朵数量，故事卡片从底部弹出。
- 浏览器不支持 3D 时：自动显示一个干净的纯文字版本，内容一样。
